# 糖果消消乐 - 微信小游戏上架指南

## 一、项目结构

```
match3-wxgame/
├── game.js              # 游戏主逻辑（纯Canvas渲染）
├── game.json            # 小游戏配置
├── project.config.json  # 项目配置
├── index.html           # 浏览器测试用（上架不需要）
└── test-adapter.js      # 浏览器测试适配器（上架不需要）
```

## 二、上架流程（2025-2026最新）

### 1. 注册账号 & 获取AppID

1. 访问 [微信公众平台](https://mp.weixin.qq.com/) → 注册 → 选择「小游戏」
2. 主体类型：**个人**（免费游戏推荐）或 **企业**（需要内购时）
3. 完成邮箱激活、信息填写
4. 获取 **AppID**（在「开发」→「开发设置」中）

### 2. 修改AppID

打开 `project.config.json`，将 `appid` 改为你的真实AppID：

```json
{
  "appid": "wx你的AppID"
}
```

### 3. 安装微信开发者工具

下载：[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)

### 4. 导入项目

1. 打开微信开发者工具
2. 选择「小游戏」→「导入项目」
3. 目录选择：`match3-wxgame/`
4. 填入你的 AppID
5. 点击导入

### 5. 真机调试

1. 点击工具栏「预览」→ 手机微信扫码
2. 在微信中测试游戏完整流程

### 6. 资质准备（免费游戏，无需版号）

| 资质 | 说明 | 个人主体 | 企业主体 |
|------|------|---------|---------|
| 游戏自审自查报告 | 按模板填写，打印签名按手印 | ✅ 必须 | ✅ 必须 |
| 软著/电子版权认证 | 3-5工作日（电子版）或30工作日（纸质） | ✅ 必须 | ✅ 必须 |
| 游戏版号 | 仅内购游戏需要 | ❌ 不需要 | 仅内购需要 |
| ICP备案 | 微信平台代备案，等1-4周 | ✅ 必须 | ✅ 必须 |
| 隐私协议 | 填写隐私政策URL | ✅ 必须 | ✅ 必须 |

### 7. 提交审核

1. 在开发者工具中点击「上传」→ 填写版本号和描述
2. 登录微信公众平台 → 版本管理 → 找到上传的版本
3. 点击「提交审核」
4. 填写：
   - 游戏简介
   - 游戏截图（至少4张，建议750×1334）
   - 玩法说明
   - 隐私协议URL
5. 选择类目：**游戏 → 休闲游戏 → 益智类**
6. 提交！

### 8. 审核周期

- 首次审核：约 1-2 个工作日
- 版本更新：约 2-4 小时（AI辅助审核）

## 三、注意事项

- ⚠️ 主包体积限制 **4MB** 以内（当前项目远低于限制）
- ⚠️ 免费游戏不能有内购/充值，可通过广告变现
- ⚠️ 游戏内容不得含暴力/赌博/色情元素
- ⚠️ 需要有明确的客服联系方式
- ⚠️ 二级游戏类目一旦确定发布后不可更改，请选「益智类」

## 四、变现方式

1. **激励视频广告**：复活/获得额外步数时观看广告
2. **Banner广告**：底部展示
3. 更多广告接口需接入 `wx.createRewardedVideoAd()` 等

## 五、当前游戏功能

- ✅ 8×8 网格三消核心玩法
- ✅ 滑动/点击双操作模式
- ✅ 连锁反应 + Combo提示
- ✅ 特殊糖果：条纹糖(4消)、彩色炸弹(5消)、包装糖(L形)
- ✅ 关卡系统 + 步数限制 + 目标分数
- ✅ 粒子特效 + 分数飘字
- ✅ Web Audio 音效
- ✅ 纯Canvas渲染，无DOM依赖
